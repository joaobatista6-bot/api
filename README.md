Qual API você usou: Dog CEO API — documentação: https://dog.ceo/dog-api/

O que ela devolve: A API devolve URLs de imagens de cachorros e o status da consulta.

O endereço que você chamou: https://dog.ceo/api/breed/labrador/images/random

Como rodar: Abra o index.html com um servidor local, como o Live Server do VS Code.

Uma dificuldade que você teve: A dificuldade foi organizar as informações das raças. Resolvi criando um objeto com os dados de cada raça no JavaScript.
